# Подвоз — Wildberries СЦ Подольск 3

Одно приложение, две задачи. Публикуется через GitHub Pages.

## Структура

| Файл | Назначение |
|------|-----------|
| `index.html` | Страница-хаб: выбор задачи |
| `execute.html` | **Управление подвозом** — для сотрудников: вход по ID, приём заказа (квадрат + бейдж), отметка «Готово» (КГТ/Стандарт) |
| `zayavka.html` | **Заказать подвоз** — заявка: бейдж + квадрат → таблица подвоза |
| `squares.json` | Список квадратов для заявки (редактируйте этот файл, чтобы добавить/убрать квадраты) |

## Бэкенд

Google Apps Script Web App (единый для обеих страниц):

- `action=getOldest` — получить самый старый заказ (JSONP)
- `action=completeOrder` — завершить заказ (POST, `row`, `type`, `employeeId`)
- `action=addOrder` — добавить заявку (POST, `badge`, `square`)
